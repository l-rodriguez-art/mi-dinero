MI DINERO — PWA LOCAL

Archivos:
- index.html
- manifest.json
- service-worker.js
- icon.svg

Para instalarla como app:
1. Sube estos archivos a un hosting HTTPS (GitHub Pages funciona).
2. Abre la URL desde Chrome en Android.
3. Usa "Instalar aplicación" o "Agregar a pantalla de inicio".
4. Aparecerá el icono "Mi Dinero".

Los presupuestos y movimientos se guardan localmente en el navegador del dispositivo.
El respaldo JSON permite mover los datos manualmente a otro dispositivo.

Nota: el modo PWA/offline requiere HTTPS cuando está publicada.
